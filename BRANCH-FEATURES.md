# Что сделано в ветке `windows`

Легенда: `-[windows]-` — работает/появилось только на Windows, `-[all]-` — на всех
платформах, `-[unix]-` — только macOS/Linux.

## Порт на Windows

-[windows]- Nebula собирается и работает на Windows 10/11 — весь воркспейс проходит build, clippy и тесты.
-[windows]- Демон и TUI общаются по локальному TCP с токеном вместо unix-сокета.
-[windows]- Второй демон не поднимется поверх первого; `nebula kill` и проверка версий работают.
-[windows]- Демон живёт в фоне без окна консоли и переживает закрытие клиента.
-[windows]- Терминальные сессии полноценно работают: запуск агента, вывод, история, статус завершения.
-[windows]- При закрытии сессии умирает всё дерево процессов агента — ничего не висит в фоне.
-[windows]- Агентские CLI, установленные через npm, запускаются корректно.
-[windows]- Метрики памяти сессий считаются нативно.
-[windows]- Пути с `~/` резолвятся, даже если `HOME` не задан.
-[windows]- Никаких мигающих чёрных окон от фоновых вызовов git/gh.
-[windows]- Ссылки (например, Enter на строке PR) открываются в браузере.
-[windows]- Редактор из модалки запускается, даже если `vim`/`nano` нет в PATH.
-[windows]- Файлы в UTF-8 открываются в редакторе читаемо, без кракозябр.
-[windows]- Shift+Enter и другие аккорды с Ctrl/Alt доходят до консольных программ. (в работе, не закоммичено)
-[windows]- Многострочная вставка (Ctrl+V) уходит агенту одним сообщением, а не строка-за-строкой.
-[windows]- `nebula ssh` корректно отдаёт консоль, код возврата и Ctrl+C.
-[windows]- `nebula upgrade` честно отказывается и подсказывает `cargo install`.
-[windows]- Сквозные smoke-тесты транспорта, токена и блокировки демона.

## Функциональность (все платформы)

-[all]- Поддержка GitLab наравне с GitHub: MR, комментарии, аппрувы и диффы в том же интерфейсе, включая self-hosted.
-[all]- Строки OPEN PRS показывают статус ревью и пайплайна иконками слева от номера.
-[all]- Настройка «Open PRs filter»: группа OPEN PRS показывает все открытые PR, только мои или те, где я участвую.
-[all]- Если включён ровно один тип агента, `n` сразу ведёт к именованию сессии, без выбора из одного пункта.
-[all]- Инструкция по доступу к TUI с телефона через Tailscale (`docs/remote-access-tailscale.md`).
